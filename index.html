What is this

This is a collection of projects created by pooiod7 to make Scratch 2 functional in modern browsers.

Projects

ScratchFlash

This project is a fork of s2online

ScratchFlash is a slightly modified build of Scratch 2 that uses Ruffle to run in modern browsers.

Online projects work through cloud variable support. Support for local storage and web fetching is also included (see fetch demo).

Gamepad and controller support is also included out of the box.


Current issues:

  • Sound volume can not be changed while playing
  • Sounds lag when starting
  • Large sounds not playing
  • No noteblock sound support

ScratchX

ScratchX is brought back using the same Scratch 2 SWF (since ScratchX was built into every copy of Scratch 2), with added Scratch 3 extension support.

Convert SB3 projects to SB2

Convert modern Scratch 3 (.sb3) projects into Scratch 2 (.sb2) projects, using just your browser.

The conversion library was initially based on RexScratch/sb3tosb2.
